## Key Takeaways



1. The hand rule `stale x visible` is a transparent, explainable baseline.

2. The decision tree is also readable: `if impressions <= X then ... else ...`.

3. Depth-3 trees capture more signal but are harder to read — the trade-off

   between interpretability and performance.

4. **Never feed the outcome back in** — `trend_direction` and `trend_pct` must

   stay out of the feature list, or the model is learning from leaked labels.
